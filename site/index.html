Prisma

One app for every light in your PC. Motherboard, RAM, GPU, fan strips, keyboard and mouse, driven from a single frame loop so they all move in step. No vendor suites, no cloud, no account.

Download Prisma.exe v2.0.0 · 21 Sep 2026 For Windows 10 and 11. Or the small zip, which needs the .NET 8 Desktop Runtime.

What it does

Everything at a glance

Click the rainbow title for what's playing, how many LEDs are lit, which devices and backends are in use, and how each one is driven.

One device, its own look

Right-click any device for its own colour or effect. Identify blinks it so you know which one it is; Reset brings it back to the global look.

Any colour

A colour wheel with a hex field and quick swatches. Colours you use are kept as swatches in the main window.

The pictures come from Prisma's built-in preview windows, filled with sample devices.

12 effects

  • Static
  • Rainbow wave
  • Colour cycle
  • Breathing
  • Strobe
  • Two-colour gradient
  • Comet
  • Twinkle
  • Fire
  • Ambient follows your screen
  • Music reacts to system audio, with its own bass band
  • Surprise

Every device is drawn on one shared loop, 25 frames a second by default (5 to 30 in Settings), so a rainbow on the RAM lines up with the one on the fans. Devices whose firmware can run an effect on their own do so instead of being streamed, which keeps the fragile ones stable.

Set it and forget it

Automation

  • Profiles, applied with one click or automatically when a game or program starts, and undone when it closes.
  • Night schedule: lights off, or dimmed, between hours you pick.
  • Off when idle, when the PC locks, sleeps or turns the display off, and on exit.
  • Hotkeys anywhere in Windows: Ctrl+Alt+L lights on/off, Ctrl+Alt+P next profile, Ctrl+Alt+R rescan.
  • Lives in the tray, and the tray icon shows the current colour.

Reliability

  • Back after sleep. ASUS Aura boards fall back to their own rainbow on wake, and a RAM stick that shows up late can ignore colours. Prisma puts its look back after wake and again while the PC settles after boot.
  • Names the troublemaker. When another RGB app fights over the same lights, Prisma tells you which one.
  • Reconnects by itself if the OpenRGB server goes away, and notices when its device list changes.
  • Careful with Sapphire cards. Their lighting chip can lock up, so Prisma orders its writes to avoid it, and Settings has a one-click sleep to bring it back if it ever does.

What Prisma can light depends on your hardware: the list above is what it supports today. Devices are opt-in one by one, so you can leave a mouse to its own software.

Download

  1. Download Prisma.exe and run it. Nothing to install.
  2. For motherboard and RAM lighting, install OpenRGB and run its server as administrator. The tidy way: a Task Scheduler task called OpenRGB Server that starts at logon with Run with highest privileges. Prisma starts it for you when it's there.
  3. Tick the devices you want Prisma to drive, pick an effect, done.

Run only one OpenRGB. Two servers setting up the same memory bus can freeze a device until the PC is fully powered off. Prisma's conflict check is there to catch it. Windows SmartScreen may warn the first time because the app isn't signed: More info › Run anyway.

From a Stream Deck or a script

Start Prisma.exe with any of these while it's already running and the command goes to the open app. Settings › Commands can make ready-made shortcuts for you.

--toggle               lights on / off
--off                  everything off
--effect rainbow       static, rainbow, cycle, breathing, strobe, gradient,
                       comet, twinkle, fire, ambient, music, surprise, off
--color 00c8aa         6-digit hex
--brightness 60        1–100, or +10 / -10
--speed 50             1–100, or +10 / -10
--profile Gaming       a saved profile, by name
--next-profile
--show                 bring the window up
--minimized            start hidden in the tray
